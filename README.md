# Hi, I'm Tabrez 👋

I work on **complex software engineering problems** that require deep
system understanding, rigorous investigation, and verified implementation.

I’m particularly interested in problems where the difficult part is not
writing code, but understanding **what the system actually does, why it
behaves that way, and what the smallest correct change should be.**

---

## What I Do

I work through difficult engineering problems using:

**Issue → Investigation → System Reconstruction → Root Cause → Design →
Implementation → Tests → Verification → PR**

My focus is on producing changes that are:

- Evidence-driven
- Minimal and targeted
- Architecturally consistent
- Regression-protected
- Independently reviewable

## How I Investigate

Before changing code, I try to understand the system as a whole.

I investigate:

- Execution flow
- Data flow
- State and lifecycle
- Architecture and ownership
- Contracts and invariants
- Dependencies and boundaries
- Runtime behavior
- Tests and validation
- Git history
- Failure mechanisms
- Change surface and regression risk

The goal is to move from:

**Observed behavior → Evidence → Causal explanation → Correct intervention**

---

## How I Approach Changes

I prefer:

**Root cause over symptoms**

**Evidence over assumptions**

**System understanding over local fixes**

**Minimal change over unnecessary refactoring**

**Tests over confidence**

**Verification over "it should work"**
